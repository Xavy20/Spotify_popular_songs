# Spotify_popular_songs
# Customer Behavior Clustering and Predictive Modeling

## 🧠 Project Overview
This project analyzes customer behavior using clustering techniques and builds predictive models to forecast outcomes. It includes exploratory data analysis, feature engineering, unsupervised learning (clustering), and multiple supervised models for prediction and evaluation.

## 🔍 Project Structure
- `Intro_EDA.ipynb` – Initial data exploration
- `Support_EDA.ipynb` – Additional exploratory analysis and correlation checks
- `Clustering.ipynb` – Unsupervised clustering to segment data
- `Models_fitting_interpretation.ipynb` – Model training and interpretation
- `Model_predictions.ipynb` – Predictive results
- `Model_performance_validation.ipynb` – Final performance comparison

## 📊 Techniques and Technologies
- **Languages**: Python
- **Libraries**: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, statsmodels.formula.api, patsy
- **Methods**:
  - KMeans Clustering
  - Logistic Regression
  - Performance metrics (accuracy, precision, recall)

## 🧠 Key Insights
- Identified distinct clusters of customer behavior using KMeans
- Built multiple classification models with performance comparison
- Provided interpretation of key predictive features

## 📌 How to Run
1. Clone this repository
2. Open notebooks in Jupyter
3. Run in order:
   - `Intro_EDA.ipynb`
   - `Clustering.ipynb`
   - `Models_fitting_interpretation.ipynb`
   - `Model_predictions.ipynb`
   - `Model_performance_validation.ipynb`
